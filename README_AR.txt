موقع هدية لفرح ❤️
=====================

تشغيل الموقع على جهازك:
1) فك ضغط ملف farah_love_website.zip.
2) افتح مجلد farah_love_website.
3) افتح index.html بمتصفح Chrome أو Edge.

إضافة صوركم:
- حط صورة الغلاف باسم cover.jpg داخل مجلد photos.
- أضف صور الألبوم بالأسماء دي داخل photos:
  memory-1.jpg
  memory-2.jpg
  memory-3.jpg
  memory-4.jpg
  memory-5.jpg
  memory-6.jpg
- الأفضل تكون الصور JPG أو JPEG. لو الصورة PNG، حوّلها إلى JPG أو غيّر اسم الملف والمسار في script.js.
- اختار صور عندك حق مشاركتها، ولو الموقع منشور برابط عام، أي حد معاه الرابط ممكن يشوف الصور.

تعديل التواريخ والحكايات:
- افتح script.js باستخدام Notepad أو VS Code.
- أول قائمة اسمها memories: عدّل date و title و description و image لكل ذكرى.
- القائمة الثانية اسمها chapters: عدّل مراحل الـ Timeline والتواريخ والوصف.
- تاريخ بداية العلاقة مضبوط حاليًا على 18 فبراير 2025. لو حبيت تغيّره، عدّل startDate في آخر script.js.
- تقدر تعدّل رسالة الحب في index.html.

إضافة الموسيقى:
- ضع ملف MP3 تملكه أو لديك إذن باستخدامه داخل مجلد music.
- سمّ الملف بالضبط: our-song.mp3
- لا يبدأ الصوت تلقائيًا؛ الزائرة تضغط زر «شغّل موسيقانا»، لأن المتصفحات غالبًا تمنع التشغيل التلقائي.

نشر الموقع مجانًا على الإنترنت باستخدام GitHub Pages:
1) أنشئ حسابًا على https://github.com إن لم يكن لديك حساب.
2) أنشئ Repository جديدًا، مثلًا باسم farah-gift.
3) ارفع الملفات الموجودة داخل مجلد farah_love_website نفسه (index.html وstyle.css وscript.js ومجلدي photos وmusic) إلى المستودع.
4) من Settings ثم Pages، اختر Deploy from a branch.
5) اختر الفرع main والمجلد /(root)، ثم Save.
6) انتظر قليلًا حتى يظهر رابط الموقع في صفحة Pages. ابعته لفرح.
ملاحظة: لا ترفع أي معلومات شخصية أو صور لا تريد أن يراها من يصل إلى الرابط. الموقع على GitHub Pages يكون عامًا عادةً؛ الرابط غير مضمون الخصوصية.

مهم:
- الصور والموسيقى غير مرفقة في القالب؛ أضف ملفاتك بنفسك.
- لو عدّلت الملفات بعد النشر، ارفع النسخ المعدّلة مرة أخرى للمستودع.
- الخطوط قد تحتاج إنترنت لتظهر بخط Cairo وPlayfair Display؛ الموقع يظل قابلًا للاستخدام لو لم تُحمّل الخطوط.
